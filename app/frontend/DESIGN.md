# 雀神 · 单机麻将 设计规范

## Direction & Layout
- 目的：一人对战三名电脑的单机麻将。氛围是“老茶馆里的实木麻将桌”：深翡翠绿绒布台面 + 深色胡桃木桌框 + 象牙色牌面 + 绿色牌背。不要做成科技风、霓虹风或扁平卡片仪表盘。
- 首屏视觉标志：占满视口的绿绒牌桌，中央罗盘方位框（东南西北 + 余牌数 + 最后打出的大号牌），玩家手牌位于底部，尺寸最大、可点击。参考：真实的自动麻将桌俯视图。
- 布局：牌桌为 3×3 网格（上/左/右为电脑，中央为四家牌河 + 罗盘，底部为玩家区）。最大宽度 1200px，桌框 10px 木边，内边距 8px（移动）/16px（≥640px）。
- 断点：<640px 使用小号牌（手牌 25×36px），640–1023px 中号（38×54px），≥1024px 大号（46×64px）。左右电脑手牌竖排，上方横排。
- Do：牌面汉字清晰（一二三… + 万/筒/条，东南西北中发白）；当前行动者金色描边；最新打出的牌金色高亮。
- Don't：不要使用 Unicode 麻将 emoji（各平台渲染不一）；不要蓝紫渐变；不要把操作按钮做成与背景同色。

## Tokens
- 颜色：桌框木 #5A3418 / 背景 #2B1A0E；绒布 #0E5A40（中心 #17704F，边缘 #0A4531）；深绒面板 #08301F；牌面象牙 #FBF6E9，牌边 #D9CFB4，牌厚度绿 #2E8B57；牌背 #2FA36B→#1C7A4C；强调金 #E8B04B（稀缺使用：当前回合、标题、最后一张）；胡牌红 #B3261E；文字米白 #F4EBD0；万 #B3261E，筒 #1F5FA8，条 #1E7A46，风牌 #1E2A38；正分 #9BE3B9，负分 #FF9C8F。
- 字体：标题 “Ma Shan Zheng”（毛笔书法，32–40px）；牌面 “Noto Serif SC” 900；正文 “Noto Sans SC” 400/600，14px/1.5；按钮 15px 700。
- 间距：4/8/12/16/24px。圆角：牌 5px，按钮 999px（胶囊），面板 16px，牌桌 28px。
- 层级：牌用 `0 3px 0 #2E8B57, 0 4px 6px rgba(0,0,0,.35)` 模拟厚度；面板用 inset 阴影；结算浮层 rgba(0,0,0,.55) 遮罩。

## Shared Patterns & States
- 麻将牌 MjTile：尺寸 hand / meld / river / mini / big / back / sideBack；可点击时 hover 上移 6px（150ms ease-out）；高亮态金色 2px 外环。
- 座位徽章：胶囊，含门风、名字、庄标（红底白字）、积分；当前行动者金边。
- 操作按钮：胡（红底白字）、杠/碰/吃（金底深棕字）、过（透明底米白描边）；最小高度 40px。
- 结算面板：象牙底深棕字，展示胡牌手牌、番型明细、各家得失分，按钮“下一局”“重新开始”。
- 动效克制：只用于手牌悬停与回合高亮；内容首屏即可见。
- 可访问性：可点击牌带 aria-label（如“三万”），按钮有明确文字，焦点环金色。

## Media
- 纯游戏操作界面，不需要照片或插画；牌面、牌桌全部由 CSS 绘制，保证清晰与一致。
